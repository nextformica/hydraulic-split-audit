# Release scope and decision record

This release was assembled from the audited hydraulic manuscript package on 2026-10-17. The publication unit is a dataset-specific application evaluation and protocol audit. The decision to publish only the minimum chain was made to avoid exposing unrelated experiments, historical drafts, user-provided documents, local paths, browser artifacts, and raw data that are already distributed by UCI.

The computational claims are limited to the supplied UCI archive, the observed four accumulator levels, the stated feature extraction, and the stated grouped outer folds. The code does not support claims of a new diagnostic algorithm or external industrial validation.

The accompanying manuscript contains the full research narrative. This release record is intentionally concise and contains no personal file paths or private conversation content.
